# Relatório de Vendas – Atualização com Foco na Experiência do Usuário

Projeto desenvolvido como parte do **bootcamp da DIO: Klabin - Excel e Power BI Dashboards**.

## 📌 Desafio do Projeto
**Desafio de Projeto – Atualizando Relatório Financeiro com Foco na Experiência do Usuário**

O objetivo foi aprimorar um relatório de vendas previamente criado, aplicando princípios de design e usabilidade para tornar a navegação, visualização e interpretação dos dados muito mais intuitivas. A tarefa consistiu em revisar o layout, reorganizar elementos e aprimorar a experiência do usuário utilizando boas práticas de design aplicadas ao Power BI.

Os pilares orientadores foram:
- **Posicionamento** dos elementos
- **Contraste** entre gráficos, textos e fundo
- **Proporção Áurea** para destaque visual
- **Segmentação de dados** clara e acessível

---

## 🎯 Objetivo
Transformar o relatório existente em uma versão mais intuitiva, profissional e eficiente, focada na clareza visual e na facilitação da tomada de decisões. O desafio também reforça princípios essenciais de design aplicados a dashboards.

---

## 🛠️ Ferramentas Utilizadas
- **Power BI Desktop**
- Princípios de design e UX aplicados a visualizações de dados

---

## 📄 Estrutura do Relatório
O relatório atualizado é composto por **3 páginas principais**:

### **1. Sales**
- Indicadores gerais de vendas
- Visuais alternáveis por botões
- Navegação lateral

### **2. Profit**
- Informações de lucratividade
- Uso de matriz para organização dos dados
- Destaque visual através da proporção áurea

### **3. Report**
- Visão consolidada
- Gráficos suplementares organizados de forma clara
- Segmentações de dados estratégicas

---

## 🧭 Navegabilidade e Interações
Para melhorar a experiência do usuário, foram adicionados:

### 🔘 **Botões de Navegação**
- Avançar
- Voltar
- Acessar diretamente qualquer página via menu superior ou lateral

### 🗂️ **Menus de Navegação Interna**
Presente em todas as páginas, contendo o nome de cada seção do relatório para facilitar a localização e o fluxo de leitura.

### 📅 **Filtro por Período de Datas**
- Controle interativo de tempo
- Botão dedicado para **limpar seleção** rapidamente

### 🔄 **Botões de Alteração de Visuais**
Permitem alternar gráficos dentro do mesmo espaço, otimizando o layout e oferecendo múltiplas perspectivas dos dados sem poluir a página.

---

## 🎨 Boas Práticas Aplicadas
O relatório incorpora diversos cuidados de design e desempenho, incluindo:

- **Posicionamento estratégico** dos elementos, garantindo hierarquia visual.
- **Contraste** adequado entre textos, gráficos e fundo, melhorando a legibilidade.
- Aplicação da **Proporção Áurea** para destacar o visual mais importante da página.
- Uso eficiente da **matriz** para estruturar dados complexos.
- **Otimização de desempenho**, priorizando a ordem de carregamento dos elementos.

## 🧾 Conclusão
Este projeto demonstra a importância de unir visualização de dados com experiência do usuário. O relatório atualizado se torna mais limpo, intuitivo e funcional, permitindo que qualquer usuário — iniciante ou avançado — compreenda rapidamente as informações e navegue com facilidade. A aplicação de princípios como contraste, proporção e segmentação correta reforça o valor do design em análises de dados.

O resultado final é um dashboard mais profissional, acessível e agradável de usar.
